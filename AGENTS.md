# Repository guidance

- Keep skills self-contained and instructions specific to their actual workflow.
- Keep authored files at or below 150 lines and source code free of extra comments.
- Never commit live subscription URLs, credentials, raw profiles, or machine logs.
- Discover OS, executable paths, ports, and connection state instead of assuming them.
- Document which platforms were exercised and which have reference guidance only.
- Preserve unrelated changes and verify frontmatter, links, and executable examples.
- Update CATALOG.md and the README/HELP counts when the skill collection changes.
- Follow the user's local commit and permission rules; publishing needs authorization.
